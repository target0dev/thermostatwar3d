# Thermostat War 3D (browser version 1.0.0)

One office. One thermostat. Four coworkers who all want a different temperature.
Sneak out of your cubicle, nudge the dial your way, and make sure someone else takes the blame.

**Play in your browser:** https://target0dev.github.io/thermostatwar3d/
Keyboard and mouse: WASD to walk, click then mouse (or J/L) to look, R/F to nudge the dial warmer/cooler,
E to look around or take supplies, Q to use an item, V to change the camera, Esc for the menu.

Multiplayer in the browser: one player presses Multiplayer > Host a game and shares the room code;
friends type the code and press Join (2-4 players, AI fills empty desks).
The `server` folder is the small online game server that passes messages between players
(runs on a free Render.com web service; it knows nothing about the game rules).
Made with the Godot Engine (MIT license, see GODOT_LICENSE.txt).
Characters: Quaternius "Ultimate Animated Character Pack" (CC0). No AI-generated art or audio.
